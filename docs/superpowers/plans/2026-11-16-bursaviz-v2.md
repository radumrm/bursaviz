# BursaViz v2 Implementation Plan

> **For agentic workers:** each task below is owned by one agent and runs in parallel with the others.
> Implement **only your task**, touch **only the files your task lists**, and code against the frozen
> contracts in "Shared contracts". Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 15M/30M chart intervals, a chart-indicator menu, a dark/light theme switch, a display-currency
switch (RON / EUR / USD), and a better news + data scraper.

**Architecture:** unchanged — `scripts/scrape.ts` writes static JSON to `public/data/`, the Vite + React site only
reads it. New site-wide state (theme, currency, FX rates) lives in one React context, `src/lib/settings.tsx`.
Pure math stays in `src/lib/indicators.ts` / `src/lib/aggregate.ts` and gets unit tests.

**Tech Stack:** Node 26 (runs `.ts` directly; use only erasable TS syntax — no enums, no parameter properties),
React 19, Vite 8, TypeScript 7, lightweight-charts 5.3, yahoo-finance2 4, `node --test`.

**Spec:** the user's request of 2026-11-16 (this document's Goal + tasks are the written form of it). Code map:
`graphify-out/GRAPH_REPORT.md` — read it first instead of exploring.

## Global Constraints

- Finance labels stay English (as on FinViz); site chrome and messages are Romanian with correct diacritics.
- Missing data renders as `-` (with a `title` tooltip where a reason is known). Never invent values.
- Must keep working on an **old snapshot**: `bars.m`, `fx.json`, `market-news.json`, `statementsCurrency`,
  `dividends`, `snapshot.divGr3/divGr5` may all be absent.
- Yahoo only through `yahoo-finance2`. On HTTP 429 stop and report — no user-agent tricks, no retries on 429.
- Do not read `public/data/**` into context (21 MB). Inspect it with small `node -e` / `python3 -I -c` one-liners.
- Relative imports inside files that Node executes (`scripts/**`, `tests/**`, and anything they import at runtime)
  must carry the `.ts` extension. `src/lib/indicators.ts` and `src/lib/aggregate.ts` may only have type imports.
- No new npm dependencies.
- Do not edit: `src/lib/types.ts`, `src/lib/settings.tsx`, `package.json`, `CLAUDE.md`, or any file owned by
  another task. If a contract is wrong, say so in your report instead of changing it.
- Done means: `npx tsc --noEmit` exits 0 and `npm test` passes. Do not start the dev server (one is already
  running on :5173) and do not run `vite build`.

## Shared contracts (already in the repo — read these two files)

- `src/lib/types.ts` — `BarsFile.m?` (15-minute bars), `FxFile`, `MarketNewsFile`, `NewsItem.tickers?`,
  `StockFile.statementsCurrency?`, `StockFile.dividends?`, `Currency`.
- `src/lib/settings.tsx` — `SettingsProvider`, `useSettings(): { theme, setTheme, currency, setCurrency,
  fxReady, convert(amount, from = "RON", day?), unit(from = "RON") }`, `CURRENCIES`.
  `theme` is mirrored to `<html data-theme="dark|light">`.
- New snapshot keys written by Task 1, read by Task 3: `divGr3`, `divGr5` (fractions, may be null/absent).
- Which currency a number is in: snapshot `income` and `sales`, and everything under `statements`, are in
  `stock.statementsCurrency ?? stock.currency`; every other money value (prices, market cap, EV, per-share
  values, dividends, ATR, target) is in `stock.currency` (RON).

## Review Focus

1. **Old snapshot** — site opened before the scraper is re-run: no `bars.m` → 15M/30M buttons disabled with a
   tooltip; no `fx.json` → currency picker disabled, everything in RON; no `market-news.json` → panel hidden.
2. **Too few bars for an indicator** (SMA 200 on monthly candles, MACD on a 3-week-old listing) → no line,
   legend shows `-`, no exception.
3. **Short aliases in news matching** — tickers like `M`, `ONE`, `EL`, `PE`, `AQ` must not match ordinary words;
   "Electrica" must not match "electricitate".
4. **Statements not in RON** (e.g. an issuer reporting in EUR) — labels and conversions use the statement
   currency, never an assumed RON.
5. **Currency switch on historical data** — a chart or statement date with no FX row (weekend, before the FX
   history starts) uses the nearest earlier rate, else the first/latest; never `NaN`.
6. **Bad stored settings** — unknown theme / currency / indicator ids in `localStorage`, or storage disabled →
   defaults, no crash.

    `isRelevant("Prețul la electricitate crește", ["Electrica"])` → false (whole-word match);
    `isRelevant("Acțiunile TLV urcă", ["Banca Transilvania", "TLV"])` → true;

    diacritic-insensitive: `isRelevant("Santierul Naval Orsova", ["Șantierul Naval Orșova"])` → true.
  - `dedupeNews`: two items whose `normalizeTitle` is equal collapse to one — the earlier `date` wins; items with
    different titles are all kept; output sorted newest first.
  - `parseRss(xml)`: from a two-`<item>` fixture returns title without the trailing `" - <source>"`, the link,
    the source, ISO date; decodes `&amp;` and `&#39;`; skips an item with no `pubDate`.
  - `tagTickers("Banca Transilvania și Romgaz conduc tranzacțiile", defs)` → `["TLV", "SNG"]`.
