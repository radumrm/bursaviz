# BursaViz v3 — shared brief for parallel agents

Six agents work in the same tree at the same time. Each owns a short list of files and edits nothing else.
Read this page, `CLAUDE.md` and `graphify-out/GRAPH_REPORT.md` (a 5 KB code map) before opening source files.

## What exists

FinViz-style site for the Bucharest Stock Exchange. `scripts/scrape.ts` writes static JSON to `public/data/`;
a Vite + React 19 + TypeScript site reads it. Hash routing (`src/lib/router.ts`). No backend, no new npm
dependencies. Live at GitHub Pages under a sub-path, so every data URL goes through `dataUrl()` in `src/lib/data.ts`
(with the `useJson` hook, which caches).

Already wired for this round (do not re-wire):
- Routes and nav links: `#/watchlist`, `#/portfolio`, `#/compare?t=TLV,SNP`, `#/calendar`, `#/news`;
  helpers `pageHref`, `compareHref`, `writePageQuery`, `readHashQuery`, `stockHref` in `router.ts`.
- `src/App.tsx` renders `<Watchlist>`, `<Portfolio>`, `<Compare>`, `<Calendar>`, `<NewsPage>` (each gets
  `{ index: IndexFile | null }`), the stock page renders `<Dividends stock>` and `<PeersTable stock index>`,
  the home page renders `<IndexStrip />`. These are placeholders for their owners to replace — keep the export
  name and props.
- Favourites: `useWatchlist()`, `toggleWatch()`, `setWatchlist()` in `src/lib/watchlist.ts`; `<Star ticker small? />`.
- `PriceChart` receives `events?: ChartEvents`.
- Types in `src/lib/types.ts`: `IndexRow`, `StockFile`, `BarsFile`, `CalendarFile`, `IndicesFile`, `ChartEvents`,
  `MarketNewsFile` (also the shape of the new `news-all.json`).

## Rules

- **File ownership is strict.** Edit only the files your task lists (and new files you create under the paths it
  names). Do not touch `src/App.tsx`, `src/lib/router.ts`, `src/lib/types.ts`, `src/lib/settings.tsx`,
  `src/lib/watchlist.ts`, `src/styles.css`, `src/pages/Home.tsx`, `src/pages/Stock.tsx`, `package.json`.
  If a shared contract is wrong or missing something, say so in your report.
- **Styles** go in your own `.css` file imported by your component, using the theme variables defined at the top of
  `src/styles.css` (`--page`, `--bg`, `--bg-deep`, `--bg-raised`, `--line`, `--line-soft`, `--text`, `--text-soft`,
  `--text-strong`, `--muted`, `--dim`, `--blue`, `--green`, `--red`, `--row-hover`, `--shadow`, `--radius`).
  No hard-coded text or background colours: both the dark and the light theme must work. Existing shared classes you
  may reuse by name: `.wrap`, `.stack`, `.panel`, `.panel-head`, `.sec-head`, `.seg` (segmented buttons), `.empty`,
  `.pos` / `.neg`, `.num`, `.dim`, `.link-btn`, `.state`.
- **Money** shown in the UI goes through `useSettings().convert(amount, from = "RON", day?)` and `unit(from)`
  (display currency can be RON / EUR / USD). Number formatting: helpers in `src/lib/format.ts`.
- **Language:** interface text Romanian with correct diacritics; finance terms stay English as on FinViz
  (P/E, EPS, Market Cap, Dividend Yield…).
- **Missing data** shows as `-` or a plain empty state. Never invent values. Every new data file may be absent
  (old snapshot): the UI must not crash and should hide or explain.
- **Phones:** at 360–430 px wide the page must not scroll sideways; wide tables scroll inside their own container;
  tap targets about 40 px; text at least 11 px. Desktop is the primary layout (dense, FinViz-like).
- **Never read `public/data/**` with a file-reading tool** (22 MB). Inspect with short `node -e` / `python3 -I -c`
  one-liners that print a few fields.
- Node 26 runs `.ts` directly: relative imports in files Node executes (`scripts/**`, `tests/**`, and what they
  import at runtime, e.g. `src/lib/indicators.ts`, `src/lib/aggregate.ts`) need the `.ts` extension and only
  erasable TypeScript syntax (no enums, no parameter properties). Tests: `npm test` (`node --test "tests/**/*.test.ts"`).
- Yahoo only through `yahoo-finance2`. On HTTP 429 stop and report — no retries around it, no header tricks.
- A dev server with hot reload is already running on http://localhost:5173. Do not start another, do not run
  `vite build`, do not commit or push.
- `npx tsc --noEmit` checks the whole repo, including files other agents are mid-edit on. Judge your task by
  errors in your own files; if another agent's file breaks the page in a screenshot, wait a minute and retry
  (up to three times) rather than fixing it.
